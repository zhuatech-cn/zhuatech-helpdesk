# 企业服务台与工单管理系统企业能力

## 领域覆盖

- **自助服务门户**：提供提单、进度查询、补充材料和服务评价
- **服务目录**：定义服务项、表单、承诺时限、责任组和审批
- **工单中心**：统一登记事件、请求、投诉和咨询工单
- **队列与分派**：按技能、组织、值班、负载和优先级自动路由
- **SLA管理**：配置响应与解决目标、暂停规则、预警和违约升级
- **重大工单升级**：触发分级响应、管理层通知、会商和复盘
- **服务知识库**：维护标准答案、解决方案、版本、审核和使用反馈
- **满意度与质检**：执行评价、回访、抽检、申诉和改进计划
- **服务运营分析**：分析首响、解决率、积压、违约和人员负载

## 横向控制基线

- ADMIN 与 OPERATOR 权限分离，管理员审批由服务端强制校验；
- 模块白名单、字段约束、唯一编号、乐观锁和合法状态迁移；
- 企业控制项支持组织、期间、责任人、风险、期限和幂等键；
- 经办与复核职责分离，办结前至少登记一份带 SHA-256 的业务凭证；
- 外部系统同步保存成功、失败、回执编号和审计详情；
- 支持组合检索、分页、逾期筛选、CSV 导出、评论与时间线；
- `/api/domain/decision` 对企业服务台与工单管理系统关键场景返回决策、0–100评分、计算指标和处置动作；
- prod profile 对默认账号密码、数据库口令和不安全跨域来源执行启动门禁。

## 生产适配

真实 `IAM`、IAM、消息、对象存储和第三方供应商接口只预留集成边界，由部署企业自行配置。生产上线前必须完成权限矩阵、数据映射、容量压测、灾备演练、安全评估与用户验收。
