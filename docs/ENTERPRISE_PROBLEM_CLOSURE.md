# 企业级问题关闭治理

## 业务目标

将反复出现的事件从临时恢复推进到根因消除，防止问题记录在缺少永久修复、业务验收或稳定性证据时被提前关闭。

## 关闭门禁

- 必须完成根因验证、受影响服务及配置项映射、永久修复和关联事件清零。
- 必须保留变更验证证据，达到稳定性观察要求并取得业务服务负责人验收。
- 经办人与关闭复核人必须职责分离，问题全程审计证据必须完整。
- 临时规避方案、知识文章和残余风险接受作为待复核行动项。

## 接口与决策

`POST /api/enterprise/helpdesk/problem-closure`

返回 `CLOSE`、`REVIEW` 或 `BLOCKED`，并给出阻断原因和行动清单。监控、CMDB、变更和知识库仅预留标准对接方式，由部署方自行配置。
